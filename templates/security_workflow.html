Implementation evidence

The pipeline is implemented in crud/services/hybrid_security.py and is deliberately separated from views so the same code can run from an upload handler, background worker, or command-line process.

  • Per-file AES keys are derived through ephemeral ECDH, rather than stored beside encrypted data.
  • AES-GCM detects encrypted-payload tampering; SHA-256 verifies the recovered original data.
  • Capacity and malformed-payload checks fail safely before data is returned.
